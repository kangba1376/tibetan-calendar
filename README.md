# རབ་ལོ་དང་སྤྱི་ལོ་བརྗེ་སྒྱུར། 藏历公历互查

输入公历年份，查询对应藏历年号（五行 · 阴阳 · 生肖）与饶迥年名，并在页面上显示当天对应的藏历日期。

**完全免费、无广告、无会员，可离线使用。**

## 使用

直接双击 `index.html` 即可，无需安装、无需联网，也没有任何依赖。

- 年份输入框：`−` / `+` 逐年调整，直接输入年份后按「འཚོལ་བཤེར།」
- 「ད་ལོ།」：跳回当前年份
- 页面底部一行显示今天的公历日期与藏历日期

## 数据

- **年号数据**：藏历 60 年循环（五行 5 × 阴阳 2 × 生肖 12），公历 27–2600 年由同一循环规则唯一定位，已与原始数据表 60 行 × 26 个年份列逐项比对，0 处不一致。
- **逐日数据**：2026-01-01 至 2027-12-31 共 730 天，按藏医院公布的藏历历书录入，闰月、缺日、闰日均照原表记录，不作推算。2028 年起暂无逐日数据，该行留空（年份查询不受影响）。

## 字体

页面已内嵌藏文字体（Yuchi Wujin Labuleng），单个 HTML 文件约 520 KB，可直接离线分发。

若需更换字体，修改 `template.html` 中的字体 base64 与 `font-family` 即可。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（Public）
2. 上传本目录的 `index.html` 和 `README.md` 到仓库根目录
3. Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` + `/ (root)`，保存
4. 等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

## 说明

本项目的年号数据源自藏历 60 年循环规则，供学习与查阅使用；如用于正式历算发布，请以西藏自治区藏医院天文历算研究所出版的当年历书为准。
